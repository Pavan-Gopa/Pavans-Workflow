# Accessibility

- Preserve semantic HTML/native controls when available.
- Every interaction must be keyboard reachable and have a visible focus state.
- Do not communicate status by color alone.
- Maintain meaningful labels, names, and state announcements.
- Respect reduced-motion preferences and avoid motion that is not functional.
- Maintain readable contrast and avoid tiny low-contrast metadata.
- Preserve zoom, text resizing, localization, and screen-reader order.
- Terminal interfaces need stable markers, readable text labels, and no reliance
  on a single glyph or color for meaning.
